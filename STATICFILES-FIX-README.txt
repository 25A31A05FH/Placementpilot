PlacementPilot static-file test fix

This update fixes the Django test error:
  ValueError: Missing staticfiles manifest entry for 'css/app.css'

Replace the config/settings.py file in your existing project with the file at:
  PlacementPilot-Python/config/settings.py

The settings now use Django's ordinary static-file storage for local development
and Django tests. Production continues to use WhiteNoise compressed manifest
storage, which is generated by `python manage.py collectstatic --noinput` during
deployment.

No database migration is needed. Do not delete db.sqlite3 or your .venv folder.
